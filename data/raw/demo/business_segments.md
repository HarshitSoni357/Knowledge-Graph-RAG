# Microsoft Business Segments

Productivity and Business Processes is a BusinessSegment.

Intelligent Cloud is a BusinessSegment.

More Personal Computing is a BusinessSegment.

Microsoft operates the Productivity and Business Processes segment.

Microsoft operates the Intelligent Cloud segment.

Microsoft operates the More Personal Computing segment.

Azure is a Product.

Azure is part of Intelligent Cloud.

Microsoft 365 is a Product.

Microsoft 365 is part of Productivity and Business Processes.

Windows is a Product.

Windows is part of More Personal Computing.

Xbox is a Product.

Xbox is part of More Personal Computing.
